# picdance

多人即時貼紙派對牆，使用 Three.js，支援音樂互動與 AR。

## 功能需求

- 所有人進入共同畫面，看得到彼此上傳的圖片貼紙。
- 整張圖片跟著音樂彈跳、搖擺與縮放。
- 每張貼紙加入後停留約 60 秒。
- 同一房間最多同時存在 30 張貼紙。

## 技術方向

- Three.js：貼紙舞台與跳舞動畫。
- Web Audio API：音樂分析。
- WebXR：支援裝置上的 AR 舞台；不支援時使用一般 3D 畫面。
- 即時服務：同步貼紙、伺服器計時與名額。
- 圖片暫存：供參與者讀取，並安排到期清理。
- GitHub：管理程式碼與版本。

AR 初步規劃為各裝置自行放置舞台，共享貼紙資料，不包含跨裝置實體空間錨點。
