# picdance

多人即時 3D 繪圖派對。使用者在繪圖板創作，將作品送入共同 3D 場景，跟著音樂跳舞。

## 目前功能規格

- 網站開啟後，顯示一個預先設定的 3D 立體場景。
- 使用者可在繪圖板自由畫出圖形，送出後成為場景中的平面圖片貼紙。
- 作品保留透明背景，在場景裡跟著音樂彈跳、搖擺與縮放；不自動轉為立體模型。
- 所有人看見同一房間的作品與加入／移除狀態。
- 每張作品從伺服器接受加入場景起，保留約 60 秒，到期移除。
- 每個場景最多同時存在 30 張作品。
- 新作品加入時先清除到期作品；若仍有 30 張，先移除最早加入的作品，再加入新作品。
- 最早加入以伺服器加入順序判定，避免同時送出時各裝置順序不一致。
- 被新作品替換的舊作品可能停留不到 60 秒。
- 新作品僅在驗證及保存成功後取代舊作品；送出失敗不移除既有作品。
- 新進入或重新連線的使用者取得當下仍有效的作品。

## 繪圖板初步操作

畫筆、顏色、筆刷粗細、橡皮擦、復原、清空、送入場景；支援滑鼠與觸控。
具體場景美術尚待選定。

## 技術方向

- Three.js：固定 3D 場景、透明貼圖與跳舞動畫。
- Canvas：使用者繪圖與透明圖片輸出。
- Web Audio API：音樂分析。
- 即時服務：房間同步、伺服器統一計時、加入順序與 30 張上限；加入與淘汰須在伺服器原子處理。
- 圖片暫存：供參與者載入作品，過期或被替換後安排清理。
- WebXR AR：保留先前要求，待一般 3D 場景完成後整合；支援裝置可放置舞台，不支援時使用一般 3D 畫面。
- AR 各裝置自行放置舞台，共享作品資料，不包含跨裝置實體空間錨點。
